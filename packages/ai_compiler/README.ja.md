# Gyomu AI Compiler

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuエコシステム内におけるAI処理のコンパイルおよび実行基盤として機能します。その主な役割は、上位パッケージから提供されるAI処理の定義やコンテキストを、ルート、プロンプト、実行戦略、検証メカニズムなどの構造化されたコンポーネントに変換し、gyomu-aiを介した一貫した実行を実現することです。

このソフトウェアは、docstringの生成、READMEの作成、ドキュメントの翻訳、アーキテクチャのConceptのコンパイルなど、開発者ドキュメント作成タスクの自動化に特化したAIコンパイルパイプラインの群を提供します。これらの一連の自動化ワークフローを、スキーマ、コンテキストモデル、レンダラー、実行ロジックからなるモジュール式コンポーネントとして構造化します。

## アーキテクチャ

このパッケージは、開発者のドキュメント作成タスクを自動化するモジュール式のAIコンパイルパイプラインを中心に構成されています。責務は、構造化データスキーマ、コンテキストモデル、プロンプトのレンダリング、および実行ロジックを処理する協調コンポーネント間で分割されています。

データ構造とスキーマは、docstringの更新などのタスクに対する決定論的な計画とアクションを定義し、専用のコンテキストモデルは生成プロセス中の宣言やファイルを表現します。レンダリングコンポーネントは、プロジェクトの概要、アーキテクチャのConcept、READMEファイルなど、さまざまなドキュメントセクションにわたるLLMとの対話用に、会話メッセージとプロンプトをフォーマットします。 

実行コンポーネントは、状態の管理、検証の処理、およびリトライサポートの組み込みによって、ドキュメントの翻訳などの特定ワークフローを駆動します。これらのモジュール式コンポーネントが連携してソースコード入力を処理し、構造化されたAI駆動型のドキュメントを生成します。

## インストール

uv を使ってインストールします。

```bash
uv add gyomu-ai-compiler
```

## 依存関係

このパッケージでは、Success、Failure、Resultを使用した明示的な成功と失敗の表現のためにランタイム依存関係として `returns` が必要であり、スキーマと共通型のために `gyomu-schema` が必要です。

さらに、I/Oなどの汎用的なインフラストラクチャ処理には `gyomu-infra` を、LLM処理の処理には `gyomu-ai` を利用します。

## 開発

コントリビューターは、すべてのAI処理を `gyomu-ai` を経由させることで抽象化の境界を厳格に遵守し、Provider固有のロジックがコンパイラに漏洩しないようにする必要があります。AIタスクは、タスクの区別にRoute識別子のみを利用することで、基盤となるモデル設定から分離されなければなりません。さらに、すべての入力は必要な実行コンテキストを含むPromptとして明示的に構造化する必要があり、出力は消費の前に定義されたSchemaとValidatorによる検証が必須となります。

実行のレジリエンスとエラー管理は、標準化されたアーキテクチャ上の制御に従う必要があります。コントリビューターは実行の再試行を管理するために定義されたRetry戦略を使用する必要があり、失敗の原因や実行フェーズなどの診断詳細を保持する構造化されたErrorとしてすべての処理失敗を処理しなければなりません。最後に、AI処理に必要なすべての変換とコンポーネントの組み立てはCompiler層内のみで行う必要があり、Pipelineをワークフロー間でモジュール式で再利用可能なコンポーネントとして維持します。

## Public API

- Docstring Update Generation - 関数の docstring、メソッド、クラスを自動更新するための決定的な AI プラン、アクション、スキーマを構築します。
- LLM Context Rendering - さまざまなドキュメントセクションにわたって LLM コンテキストを生成するための、会話メッセージおよびプロンプトのレンダリングとフォーマットを行います。
- README Documentation Generation - プロジェクトの README ドキュメントを自動生成するための、プロンプト、ユーザーデータ構造、メッセージフローを構築します。
- Document Translation Execution - 組み込みの検証処理、リトライサポート、状態管理を備えたドキュメント翻訳パイプラインを実行します。
- Package and Directory Compilation - ソースコード入力から、高レベルなパッケージおよびディレクトリのアーキテクチャの Concept を分析してコンパイルします。
