# Gyomu AI Compiler

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomu プロジェクトにおける AI 処理のコンパイルおよび実行基盤として機能します。上位パッケージから提供される AI 処理の定義やコンテキストを、ルート、プロンプト、実行戦略、バリデーションといった構造化コンポーネントに変換し、gyomu-ai を通じて一貫して実行することが主な目的です。\n\nこれを実現するために、AI を活用したコード解析とドキュメント生成に特化したコンパイルパイプラインを提供します。Python の docstring の更新や、パッケージやディレクトリの Concept の解析に特化して設計された、コアデータスキーマ、実行コンテキスト、レンダラーを確立します。

## アーキテクチャ

このパッケージは、AIを活用したコード解析とドキュメント生成を連携させる、専用のコンパイルパイプラインを中心に構成されています。責務は、専門特化したパイプラインのドメインと共有サポートコンポーネントに分割されており、データモデリング、コンテキスト管理、レンダリングの各タスクがアーキテクチャ全体で分離されています。

docstring更新パイプラインは、専用のコンテキストおよびスキーマコンポーネントを介してPythonのドキュメント修正を処理します。コンテキストサブシステムは宣言およびファイル構造をモデル化し、一方スキーマコンポーネントは、パラメータ、例外送出、戻り値に関する決定的（deterministic）な更新計画、アクション、推論を定義します。

並行して、パッケージconceptパイプラインは、ディレクトリとパッケージの構造を処理します。そのコンテキストコンポーネントは依存関係、公開APIシンボル、モジュールを捉え、レンダラーおよび入力構築コンポーネントは、これらのデータを構造化されたパッケージ解析サマリーに統合します。

最後に、集約されたプロンプト管理コンポーネントが、コンパイラフレームワーク全体でAIとのやり取りを統一的に制御するためのプロンプトテンプレートとベース設定を提供します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-ai-compiler
```

## 依存関係

このパッケージは、動作するためにいくつかのランタイム依存関係を利用します。Success、Failure、Resultを通じた明示的な成功と失敗の表現のために `returns` パッケージを使用しています。さらに、スキーマと共通型のために `gyomu-schema`、I/Oなどの汎用的なインフラストラクチャ処理のために `gyomu-infra`、LLM処理のために `gyomu-ai` を必要とします。

## 開発

貢献者は、AIモデルやプロバイダーに直接アクセスせず、すべてのAIインタラクションが `gyomu-ai` の実行メカニズムを経由するように徹底し、関心の分離を厳格に維持する必要があります。さらに、AIタスクはRouteを通じてのみ識別され、AI処理の機能的コンテンツと基盤となるモデル設定が明確に分離されている必要があります。AIに向けられる入力は、必要な実行コンテキストを明確に表現する明示的なPromptとして構造化される必要があり、すべての出力は、後続の処理で利用される前に、定義されたSchemaとValidatorに対して厳密に検証されなければなりません。\n\nシステムの耐障害性と診断の明快さを維持するため、実行のリトライは定義されたRetry戦略によって厳格に管理される必要があり、運用の失敗は、正確な原因や実行フェーズなどの重要な診断情報を保持する構造化されたErrorとして処理されなければなりません。AI処理に必要なすべての変換、コンテキスト追跡、およびアセンブリロジックは、完全にCompilerコンポーネント内に配置される必要があります。貢献者は、プロバイダー固有のロジックを導入したり、確立されたコンパイルパイプラインをバイパスしたりすることが厳に禁止されており、これによりパッケージ全体で一貫した疎結合な実行アーキテクチャが維持されます。

## Public API

- Docstring生成と更新 - 置換アクション、パラメータ変更、raises、returnsを含む、決定論的なAI駆動のコードdocstring更新のための構造化スキーマと実行プランを定義します。
- パッケージとディレクトリの分析 - パッケージレベルおよびディレクトリレベルのConceptを処理し、パブリックAPIシンボル、依存関係、コード構造を構造化された入力と分析サマリーに統合します。
- プロンプト管理 - AIコンパイルタスクを駆動するためのプロンプトテンプレートとベース設定を管理およびロードします。
