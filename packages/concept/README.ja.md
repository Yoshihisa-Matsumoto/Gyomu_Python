# Gyomu Concept

[US English](README.md) | JP 日本語

## 概要

Gyomu Conceptは、構造化されたソフトウェアプロジェクトのConcept、ディレクトリ、およびパッケージを分析、構築、管理するために設計されたコアアーキテクチャツールです。その主な目的は、アーキテクチャの設計、責務、意図、および運用上の知識を表現する構造化されたプロジェクトモデルを確立することです。

このパッケージは、従来のドキュメントとしての役割にとどまらず、ソースコードの分析と人間が管理する知識の橋渡しをします。これにより、人間とAIの両方が効果的に活用できる統合された知識表現が作成されます。

専用のビルダーとコンテキスト管理を活用して、システムはこれらの構造化されたConceptと蓄積された知識を使用し、包括的なプロジェクトドキュメントやREADMEファイルをシームレスに生成、翻訳、およびレンダリングします。

## アーキテクチャ

Gyomu Concept パッケージは、概念モデリング、ドキュメント生成、エラー処理へと責務を分割する協調コンポーネントを中心に構成されています。パッケージおよびディレクトリ管理コンポーネントは、依存関係の収集やファイルサマリーレコードを含む、ソースコードの概念の構造解析、ロード、保存、処理を処理します。ドキュメント生成は、ベースコンテキストの初期化、アセットの翻訳、構造化出力の非同期レンダリングを行う専用コンポーネントによって管理されます。これらの生成ワークフローは、セクションや箇条書きなどの要素を構築する特殊なビルダーや、プロジェクトドキュメントを設定する README オーケストレーションユーティリティによってサポートされます。さらに、専用のエラー処理コンポーネントが、ドメイン固有の例外とフェーズ分類を定義し、概念的な実行フェーズ全体の障害を管理します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-concept
```

## 依存関係

このパッケージは、動作するためにいくつかのランタイム依存関係を必要とします。`returns` パッケージは、Success、Failure、Result を使用した成功と失敗の明示的な表現のために使用されます。 

スキーマと共通の型については、パッケージは `gyomu-schema` に依存しています。I/O などの一般的なインフラストラクチャ処理は `gyomu-infra` に依存し、README や Concept ドキュメントを作成するための LLM 処理には `gyomu-ai-compiler` が利用されます。

## 開発

コントリビューターは、ソースコード分析、Conceptの構築、ドキュメント生成の分離を厳格に維持し、それぞれを独立した責任として扱わなければなりません。Conceptモデル自体は特定のドキュメント形式や出力言語から切り離され、ソースコード分析と人間が管理するKnowledgeを統合する純粋な構造化知識モデルとして機能する必要があります。移植性を確保し、密結合を防ぐため、AI駆動の処理はすべて `gyomu-ai-compiler` を介してのみ実行し、特定のAIプロバイダーやモデルへの直接的な依存関係を避ける必要があります。

このアーキテクチャでは、実行ロジックにルールを埋め込むのではなく、ドキュメントコンテンツの翻訳方法などのドキュメント固有の設定をConcept定義にカプセル化する必要があります。コントリビューターは、ディレクトリConceptやパッケージConceptなど、さまざまな粒度にわたってConceptを管理し、それぞれの構造的な責任に合わせて調整する責任を負います。ドキュメントを構築する際、コントリビューターは、ジェネレーターがConceptとKnowledgeを入力データとして厳密に扱い、コア知識モデルを汚染することなく必要なターゲット構造に変換するようにしなければなりません。

## Public API

- ディレクトリ Concept 管理 - ソースコードディレクトリおよびそのファイル要約の構造化された Concept 表現のビルド、処理、ロード、保存を行います。
- パッケージ Concept 管理 - パッケージレベルの Concept とその依存関係コレクションの解析、ビルド、ロード、保存、処理を行います。
- ドキュメント生成とレンダリング - 定義とコンテキストを使用して、構造化されたドキュメントやセクションの生成、翻訳、レンダリング、構築を非同期で行います。
- README オーケストレーション - 概要、アーキテクチャ、依存関係、開発セクション向けの特殊なビルダーを使用して、プロジェクトの README ファイルの生成と設定をオーケストレートします。
