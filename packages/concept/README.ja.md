# Gyomu Concept

[US English](README.md) | JP 日本語

## 概要

Gyomu Conceptは、プロジェクトのアーキテクチャ、責務、設計意図、運用ナレッジを構造化するPythonのコアパッケージです。その主な目的は、コード分析と人間が管理するナレッジを組み合わせて構造化されたプロジェクトモデルを構築し、人間とAIの双方にとって共通のナレッジ表現として機能させることです。

このパッケージは、ディレクトリとパッケージの概念を構築し、その構造化された情報を使用してプロジェクトドキュメントとLLMコンテキストを生成する役割を担います。ドキュメントの構築、翻訳、セクションの組み立て、Markdownのレンダリングを含むモジュール式フレームワークを提供し、これらすべてがドメイン固有のエラーハンドリングによってサポートされています。

## アーキテクチャ

このパッケージは、ドメイン分析、ドキュメント生成、エラー管理へと責任を分割する協調コンポーネントを中心に構成されています。コアロジックは、ファイルシステムやパッケージレベルの抽象化を、出力のレンダリングから分離するように構造化されています。

プロジェクト構造の分析は、ディレクトリのConcept、ファイルのサマリーレコード、およびパッケージ依存関係の構築、処理、読み込み、保存、管理を行う専用コンポーネントによって処理されます。これらの内部機構がパスの解決と状態の永続化を処理し、正確な構造データを提供します。

ドキュメント生成フレームワークは、特化したビルダー、コンテキスト初期化処理、Markdownレンダラーと連携して、READMEファイルやLLMコンテキストなどのプロジェクト概要をコンパイルします。非同期セクションビルダーは、有効化されたセクションと翻訳を処理して、最終的な出力を組み立てます。

最後に、専用のエラーハンドリングコンポーネントが、ドメイン固有のエラークラスと実行フェーズの定義を使用して例外を分類し、Concept分析とドキュメント構築の両方のワークフローにわたって堅牢なエラー管理を保証します。

## インストール

uvを使用してインストールします。

```bash
uv add gyomu-concept
```

## 依存関係

このパッケージは、コア機能の実現にいくつかのランタイム依存関係を利用しています。成功、失敗、結果を明示的に表現するために `returns` を使用し（Success、Failure、Result）、スキーマや共通型のレポジトリとして `gyomu-schema` を使用します。 

さらに、I/O処理などの一般的なインフラストラクチャ処理には `gyomu-infra` を利用し、READMEやConceptの作成時のLLM処理には `gyomu-ai-compiler` を利用します。

## 開発

コントリビューターは、Conceptを、特定の文書フォーマットや出力言語に依存せずにプロジェクトのアーキテクチャ、責務、設計意図、運用知識を表現する構造化された知識モデルとして扱わなければなりません。Conceptは人間とAIの両方にとって共通の知識表現として機能するため、ソースコードの解析結果と人間が管理するKnowledgeを組み合わせて構築する必要があり、その際、ソースコード解析、Concept構築、文書生成を別々の責務として厳密に独立させなければなりません。さらに、パッケージやディレクトリなどの異なる粒度のConceptは、それぞれの特定の責務に従って明確に管理されなければなりません。

AI駆動のプロセスを実装する際、コントリビューターはAIプロバイダーや特定のモデルへの直接的な依存を防ぐため、それらを `gyomu-ai-compiler` を介してのみ実行しなければなりません。文書コンテンツの翻訳方法などの文書固有の定義は、AIの実行ロジック内に埋め込むのではなく、Concept側に明示的に表現されなければなりません。文書生成の際、システムはConceptとKnowledgeを文書固有の構造へ変換するための純粋な入力として扱い、ビルド、処理、依存関係の収集、永続化のすべての操作において堅牢なエラーハンドリングを行えるよう、ドメイン固有のエラー管理とフェーズ分類が適切に適用されるようにしなければなりません。

## Public API

- Document Generation Framework - ドキュメントやプロジェクト概要のドキュメント生成構造、ベースコンテキスト、レンダラー、モデル、非同期ビルディングブロックを定義します。
- Directory Concept Management - ファイルシステムパスからディレクトリのConceptおよびファイル概要レコードの構築、処理、読み込み、保存、管理を行います。
- Package Analysis and Concepts - パッケージレベルの解析、Conceptの構築、依存関係の収集、パスの解決、内部状態の永続化を処理します。
- README Generation - プロジェクトのREADMEファイルを生成するための、専用のドキュメント定義、コンテキスト、セクションビルダー、マークダウンレンダラーを提供します。
- LLM Context Generation - LLMコンテキストファイルをコンパイルするための、専用のドキュメント定義、コンテキスト、セクションビルダー、マークダウンレンダラーを提供します。
- Domain Error Handling - Conceptおよびドキュメント構築全体のエラー処理に向けて、ドメイン固有のエラークラス、例外タイプ、フェーズ分類を定義します。
