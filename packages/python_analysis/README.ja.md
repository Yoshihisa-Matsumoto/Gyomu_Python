# Gyomu Python Analysis

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuのための包括的なPythonソースコード解析基盤を提供します。その主な目的は、Pythonのプロジェクトとワークスペースをパースし、構造要素、宣言、依存関係を統一された構造化解析モデルに抽出することです。

このソフトウェアは、プロジェクトとワークスペースのコンテキストを通じて、解析対象と設定を整合的に管理します。結果とプロジェクトの状態を再利用可能な形式で表現することで、上位層がConcept、ファクト、ドキュメントのために活用できる共有の解析インフラストラクチャを提供します。

## アーキテクチャ

このパッケージは、プロジェクト管理、コード分析、AST検査、スナップショット追跡に責任を分割する、協調的なコンポーネントによって構成されています。

ワークスペースおよびプロジェクトコンテキスト層は、初期化の処理、パッケージのルートの検出、設定ファイルのパース、そしてモジュール読み込みとキャッシュの管理を行います。このコンテキストを基盤として、コアアナライザーは、Pydanticモデルを含むPythonのコード要素から、構造上のメタデータ、型、デコレータ、インポート、ドキュメント文字列、依存関係を抽出します。

詳細なコード検査のために、ASTおよび式のユーティリティがステートメントや式のパース、リテラル値の評価、シンボルおよびクラスのインデックスの構築を行います。最後に、スナップショットコンポーネントが、対象ファイルの列挙、バージョンメタデータの生成、そしてバージョン間のコードの進化を追跡するための構造的な差分の計算を通じて、プロジェクトの状態を管理します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-python-analysis
```

## 依存関係

このパッケージは、動作するためにいくつかのランタイム依存関係を必要とします。Success、Failure、および Result 型による明示的な成功と失敗の表現に `returns` を使用します。スキーマと共通の型には `gyomu-schema` を利用し、I/O などの一般的なインフラストラクチャ処理には `gyomu-infra` が対応します。さらに、Python の構文解析には `griffelib` が使用され、docstring の解析には `docstring-parser` が必要です。

## 開発

コントリビューターは、プロジェクトレベルの分析と個々のソースファイルの解析の間に厳格な境界を設け、これらの責任が完全に独立した状態を維持するようにしなければなりません。すべての分析結果は、ソースコードとプロジェクトの設定から決定論的に導出され、基盤となるソースファイルを一切変更しない、読み取り専用の構造化モデルとしてのみ公開される必要があります。分析対象、設定、モジュール検出の管理には Project Context と Workspace Context を一貫して使用する必要があり、信頼性の高いモジュール境界とソースルート定義を維持するため、パス解決はプロジェクトおよびワークスペース全体で統一されたルールに従う必要があります。

Concept、Facts、Docstring などの上位レイヤーを実装の詳細を漏らすことなくサポートするため、Python 固有の解析ロジックはすべてこの共有基盤内に集約されなければなりません。コードの変遷を追跡し後続プロセスでの再利用を可能にするため、プロジェクトの状態は Snapshot としてのみ永続化されなければならず、Snapshot の生成はドキュメントの更新などの上位レイヤーのタスクから厳密に分離されます。コントリビューターは、分析モデルがコードベースの現在の状態を表す、副作用のない信頼性の高い表現であり続けることを保証するために、これらの構造的制約を維持する必要があります。

## Public API

- Pythonコード解析 - クラス、関数、変数、PydanticモデルなどのPythonコード要素から、構造的メタデータ、型、デコレータ、定義を抽出します。
- プロジェクトとワークスペースのコンテキスト - ワークスペースの初期化、設定ファイルの解析、パッケージルートの検出、Pythonモジュールの読み込みとキャッシュを行います。
- スナップショット管理 - プロジェクトのスナップショット作成、対象ファイルの列挙、変更の追跡、バージョン間の構造的差異の計算を行います。
- ASTの検査とインデックス作成 - 抽象構文木（AST）の解析と検査を行い、Pythonの文や式の評価、シンボルインデックスの構築を行います。
