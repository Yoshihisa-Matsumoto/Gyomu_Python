# Gyomu Python Analysis

[US English](README.md) | JP 日本語

## 概要

Gyomu Python Analysis は、Python プロジェクト向けの高精度なソースコード検査および分析基盤として機能するように設計された、包括的なツールキットです。その主な目的は、Python コードベースをパースし、コード構造、宣言、依存関係を構造化された分析モデルとして抽出することです。

プロジェクトおよびワークスペースのコンテキストを通じて分析対象と設定を統一的に管理することで、分析結果とプロジェクトの状態を再利用可能な形式で扱えるようにします。これにより共通の分析基盤が確立され、Concept、事実、docstring などの上位レイヤーが標準化されたコードインサイトを効果的に活用できるようになります。

## アーキテクチャ

このパッケージは、ワークスペース管理、構文的・意味的コード分析、スナップショット追跡に責任を分割する、連携するコンポーネントを中心に構成されています。

コアのオーケストレーション層は、プロジェクトとワークスペースの初期化、ソースルートの解決、モジュールおよびファイルコンテキストの読み込みを処理します。コード分析は、シンボルコンテキストと依存関係解決データを維持しながら、クラス、関数、依存関係などのPythonコード要素から構造とメタデータを抽出する、特化したアナライザーの階層によって駆動されます。この構造的検査は、文の解析、リテラルと式の評価、シンボルインデックスの構築を行うASTおよび式処理コンポーネントによってサポートされます。

最後に、専用のスナップショットサブシステムが、ターゲットファイルの列挙、ファイルメタデータの生成、スナップショット間の差分の計算、変更管理ワークフローの検証によってプロジェクトの状態を管理します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-python-analysis
```

## 依存関係

このパッケージは、動作するためにいくつかのランタイム依存関係を利用します。Success、Failure、Resultによる明示的な成功と失敗の表現のために `returns` パッケージを使用し、スキーマおよび共通型のリポジトリとして `gyomu-schema` を使用します。 

さらに、入出力などの一般的なインフラストラクチャ処理には `gyomu-infra` が使用されます。解析タスクについては、Pythonの構文解析に `griffelib` を使用し、docstringの解析に `docstring-parser` を使用します。

## 開発

コントリビューターは、プロジェクトレベルの解析と個々のソースファイルの解析の間で関心事の分離を厳格に維持し、すべての解析結果が、基底のコードを変更することなく、ソースコードとプロジェクトの設定から一貫して導出されるようにしなければなりません。このパッケージは Project Context と Workspace Context に依存して解析対象と設定を整合的に管理し、パスの解決はワークスペースおよびプロジェクト全体を通じて統一されたルールに従う必要があります。さらに、上位層が解析ライブラリの実装詳細に直接依存するのを防ぐため、Python 固有の解析ロジックはこの共有基盤内に集約されなければならず、生成される構造化モデルは厳格に読み取り専用の状態を維持する必要があります。

状態管理は、解析対象の現在の状態を表し、ドキュメントの更新などの上位層の処理から独立して扱われなければならないスナップショットとしてプロジェクトの状態を永続化することを基盤としています。コントリビューターは、スナップショット間の差分が追跡され、変更のコミットが正しく検証されるようにすると同時に、プロジェクトの境界とソースルートを明確に定義して管理しなければなりません。これらの制約を遵守することで、このパッケージは、Concept、Facts、Docstring などの上位層に向けて、コード構造、宣言、依存関係を抽出する信頼性が高く再利用可能な基盤を維持します。

## Public API

- ワークスペースおよびプロジェクトコンテキストの管理 - Python コードベースのプロジェクトワークスペース、ソースルート、モジュールキャッシュ、設定を初期化および管理します。
- Python コード構造解析 - クラス、関数、変数、型エイリアス、インポート、デコレータ、ドキュメンテーション文字列、依存関係など、Python の構文要素に対する包括的な構造コード解析を実行します。
- AST および式処理 - Python の文、式、リテラル、抽象構文木（AST）を解析および評価し、シンボルインデックスとルックアップを構築します。
- スナップショットおよび変更追跡 - プロジェクトのスナップショットを作成し、ファイルを監視し、スナップショットの差分を計算し、変更管理ワークフローを検証します。
