# Gyomu Python Analysis

[US English](README.md) | JP 日本語

## 概要

本パッケージは、Gyomu内のPythonプロジェクトやワークスペースを対象とした、包括的な静態解析の基盤として機能します。その主な目的は、言語構造を検証し、ソースコードの構造、宣言、および依存関係を抽出し、統一された構造化解析モデルへと統合することです。

プロジェクトやワークスペースのコンテキストを通じてターゲットと設定を統一的に管理することで、解析結果やプロジェクトの状態を再利用可能な形式で扱うことができます。これにより共通基盤が構築され、Concept、Fact、docstringsなどの上位レイヤーに対して信頼性の高い構造的洞察を提供します。

## アーキテクチャ

Gyomu Python Analysis は、言語分析、ワークスペース管理、バージョン追跡に責任を分割するモジュール式コンポーネントで構成されています。このアーキテクチャは、AST パースと、言語構造、クラス、関数、型、Pydantic モデル向けの専用アナライザーを通じた Python ソース構造の分析を中心としています。

分析サブシステムは、プロジェクトおよびワークスペースの初期化処理、設定の読み込み、モジュール読み込みの管理、ファイル分析コンテキストの維持を行います。このサブシステム内では、専用コンポーネントが文や式の詳細な AST 検査に加えて、シンボルインデックス作成と識別子の解決に注力します。

これとは別に、スナップショットコンポーネントは、プロジェクトスナップショットの作成、検証、永続化によってプロジェクトのバージョン追跡を管理します。ファイル変更の追跡と差分の計算を行い、経時的なコード変更を分析することで、より広範なアーキテクチャと連携します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-python-analysis
```

## 依存関係

このパッケージは、コア機能の実現にいくつかのランタイム依存関係を利用しています。成功、失敗、結果を明示的に表現するために `returns` を使用し、共通型の保持や入出力などの一般的なインフラストラクチャ処理には `gyomu-schema` および `gyomu-infra` をリポジトリとして利用します。さらに、AST（抽象構文木）およびドキュメント文字列の解析には、それぞれ `griffelib` と `docstring-parser` が使用されます。

## 開発

コントリビューターは、すべての解析結果がソースコードとプロジェクトの設定のみから決定論的に導出されることを確認する必要があります。実行中の意図しない変更を防ぐため、基盤となるコードは厳密に読み取り専用として扱います。Project ContextとWorkspace Contextは、解析ターゲット、設定ルール、およびパス解決をスコープ全体で一元管理するための信頼の唯一の情報源として維持されなければなりません。クリーンなアーキテクチャの境界を維持するため、プロジェクトレベルの解析と個別のソースファイル解析は独立した責務として厳密に分離し、Python固有の実装詳細がこの共有基盤内にカプセル化され、上位レイヤーに漏洩しないようにする必要があります。

状態管理はプロジェクトスナップショットの作成、比較、永続化に依存します。これらは時間の経過におけるコードの正確な現在状態を表すものであり、ドキュメントの更新などの上位レイヤーの操作とは独立して処理されなければなりません。コントリビューターは、すべての出力データを、Concept、Facts、Docstringの各レイヤーによって効率的に再利用できる、不変かつ読み取り構造化されたモデルとして構築することが求められます。さらに、コードベースの変更にあたっては、明確に定義されたプロジェクト境界とソースルートを尊重し、依存レイヤーが直接的な解析ライブラリではなく、提供される解析モデルとcontextインターフェースを介してのみ相互作用する、疎結合なアーキテクチャを維持する必要があります。

## Public API

- Python言語解析 - クラス、関数、変数、インポート、依存関係、ドキュメント文字列、型エイリアス、PydanticモデルなどのPython言語の構文要素を検証します。
- AST解析とインデックス作成 - Pythonの抽象構文木（AST）を解析して文や式を検証し、シンボルのインデックスと識別子を構築します。
- ワークスペースおよびプロジェクト管理 - プロジェクトとワークスペースのコンテキストを初期化し、設定を読み込み、モジュールのロードを管理し、キャッシュを処理します。
- スナップショットとバージョン追跡 - ファイルの変更を追跡し、バージョン間の差分を検出し、プロジェクトのスナップショットの作成、検証、永続化を処理します。
