# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuエコシステム全体で共有される標準データスキーマ、型定義、エラー型、プロトコル、および一般的なユーティリティを提供します。主な目的は、Pythonの解析、concept、ドキュメント、ナレッジ、スナップショットなど、システムコンポーネント間で渡されるデータ契約を定義することです。 

このような一元的な定義を確立することで、パッケージ間の依存関係を疎結合に保ちながら、型安全性とデータの整合性を維持します。PythonのASTやコード構造の解析、構造化されたドキュメントの検証と変換、およびドメイン固有のナレッジ表現を専門としています。

## アーキテクチャ

このパッケージは、Gyomuシステム内の明確なドメイン境界に沿って責任を分割する、連携するスキーマおよびデータモデルのコンポーネントを中心に構成されています。

コアコードの解析は、特化されたPythonコンポーネントによって処理されます。Pythonコード構造コンポーネントは、シンボル、モジュール、ファイル、設定のモデルや、クラス、関数、ドキュメント文字列などの構造要素を定義します。それらと連携して、ASTおよび型コンポーネントは、式、文、型構造を表すためのスキーマモデル、ユニオン型、種別を提供します。

文書処理とドメイン知識は、専用の構造化コンポーネントによってサポートされます。文書コンポーネントは、構造化された文書、セクション、コンテンツ要素のための検証ルール、翻訳戦略、データモデルを提供します。一方、ナレッジ管理コンポーネントは、コーディング規約、運用知識、プロジェクトロードマップ、技術統合リファレンスなどの多様なドメインを構造化します。

最後に、横断的関心事は、ベースエラー、AI・設定・データベース・検証操作のためのドメイン固有のエラークラス、およびリカバリと解決戦略を定義する、一元化されたエラー処理コンポーネントによって対処されます。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-schema
```

## 依存関係

このパッケージはPydanticのバージョン2.x系と互換性があり、これを使用するように設計されています。

ランタイム依存関係として、このパッケージはスキーマ定義、データ検証、シリアライゼーション、デシリアライゼーションをPydanticに依存しています。また、returnsライブラリを使用して、Success、Failure、Result型を通じた明示的な成功および失敗の表現を提供します。

## 開発

Python Analysis、Concept、Document、Knowledge、Snapshot などのすべての Gyomu 機能において厳格な型安全性とデータの整合性を維持するため、コントリビューターは共有データコントラクトのすべてを、この基盤パッケージ内で厳密に定義する必要があります。このパッケージは他のいかなる Gyomu パッケージにも依存してはならない独立した共有基盤として機能するため、JSON、永続化層、MCP などの外部境界を横断するすべてのデータ構造は、Pydantic スキーマとしてモデル化する必要があります。コントリビューターは、内部処理のみに限定される実装固有の詳細を、これらのパブリックなスキーマから除外する必要があります。さらに、値の混同を防ぐため、識別子、パス、および意味を持つ値は、ドメインのセマンティクスを型システムに直接エンコードするために、個別の型としてカプセル化する必要があります。

Pydantic スキーマに対するアノテーションは、ランタイムの型チェックに加えて、AI コード生成、ドキュメント生成、およびナレッジ作成のための重要なメタデータを提供する場​​合に、任意ではなく必須となります。コントラクトを定義する際に、開発者は API をイミュータブルかつ宣言的に保ち、ユーティリティを厳密に汎用的に維持し、特定の Gyomu ビジネスロジックを含めないようにする必要があります。プロトコルは、どの単一パッケージの責務にも属さないパッケージ間のインターフェースコントラクトに厳格に限定する必要があり、ドメイン固有のプロトコルと具象実装はそれぞれのパッケージ内に留める必要があります。最後に、コントリビューターは、統一された構造に準拠したドメイン固有のエラーモデルを使用してエラー処理を実装することが求められ、これにより相互作用するすべてのパッケージで一貫したエラー処理が保証されます。

## Public API

- Python AST and Type Models - PythonのAST式、文、型構造を表現するためのスキーマモデル、ユニオン型、種類を定義し、解析をサポートします。
- Python Code Structure Analysis - Pythonのコード構造、シンボル、モジュール、ファイル、プロジェクト設定、依存関係に関するデータモデルとスキーマを提供します。
- Structured Document Schemas - 構造化ドキュメントとセクションのデータモデル、検証ルール、変換戦略、コンテンツ要素を定義します。
- Error Handling Models - AI、設定、データベース、検証に関する、コアのエラーハンドリングモデル、ドメイン特化型のエラークラス、解決戦略を提供します。
- Knowledge Management Schemas - コーディングガイドライン、技術文書、運用知識、ロードマップを含むナレッジドメインを構造化するためのスキーマを定義します。
