# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuシステム向けの正規データスキーマ、モデル、および共有ユーティリティを提供します。その主な目的は、Pythonの解析、構造化ドキュメント、ドメイン知識、スナップショットといったGyomu機能間でのデータ契約を定義しつつ、型安全性とデータの整合性を維持することです。 

型、エラー定義、プロトコルを集約する中心的なソースとして機能することで、個々のGyomuモジュール間の依存関係を疎結合に保ちます。PythonのASTやコード構造の解析、構造化ドキュメントの検証と変換、およびドメイン固有の知識表現のサポートを専門としています。

## アーキテクチャ

このパッケージは、ドメインおよびスキーマのタイプごとに責任を分割する、コアとなる一連の連携コンポーネントを中心に構成されています。Python解析は、AST式、文、型構造、およびクラス、関数、モジュール、プロジェクト設定などのコード要素を表す専用のモデルを通じて構造化されます。

構造化ドキュメント処理は、ドキュメント階層、コンテンツ要素、検証ルール、および翻訳戦略を定義するスキーマコンポーネントによって処理されます。ドメイン固有の要件は、AI、設定、データベース、および検証の各操作を解決戦略とともにカバーする堅牢なエラー処理モデルと、ガイドライン、ロードマップ、技術文書を構造化するナレッジ管理スキーマによってさらにサポートされます。

シリアライゼーション、タイミング、結果のラッピング、ファイルシステムとのインタラクションといった共有基盤操作は、これらすべてのコンポーネントに横断的に関与し、より広範なシステムアーキテクチャを支えています。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-schema
```

## 依存関係

このパッケージは、Pydanticバージョン2.xとの互換性を持つように設計されており、データの定義、検証、シリアライゼーション、およびデシリアライゼーションを行うPydanticスキーマとともに必要となります。さらに、ランタイムは returns パッケージを利用して、Success、Failure、Resultを用いた明示的な成功および失敗の表現を提供します。

## 開発

Python Analysis、Concept、Document、Knowledge、Snapshotの各機能間で厳密なパッケージの疎結合性と一貫したデータコントラクトを維持するため、すべての共有データ構造はカノン的なPydanticスキーマとして定義する必要があります。コントリビューターは、JSONシリアライズ、永続化層、Model Context Protocol (MCP) インターフェースなどの外部境界を越えるすべてのデータが、Pydanticを使用して完全にモデル化されていることを確認する必要があります。さらに、ランタイムの安全性を高め、AI駆動型コード生成、ドキュメント生成、知識抽出における有用性を最大限に高めるために、すべてのスキーマアノテーションは省略せずに明示的に提供し、詳細にドキュメント化する必要があります。内部処理専用のイン実装細部は非公開のままにし、公開Pydanticスキーマとして露出させないようにする必要があります。

データ交換エラーを防ぐため、値、識別子、パスを正確な型にカプセル化することで、型安全性とドメインの明確性を強制する必要があります。APIは厳密にイミュータブルかつ宣言的に設計し、パッケージ間の統一されたエラー回復を実現する共通のエラー構造に準拠した、ドメイン特有のエラーハンドリングモデルを伴う必要があります。共有ユーティリティは特定のビジネスロジックから完全に疎結合された状態を維持し、プロトコルはどの下流パッケージの責務にも属さない横断的なインターフェースコントラクトに厳密に限定する必要があります。このパッケージはGyomuエコシステム全体の基盤となる共有インフラストラクチャとして機能するため、コントリビューターは他のGyomuパッケージへの依存を防ぐことで、その独立性を厳格に維持する必要があります。

## Public API

- Python AST and Type Models - PythonのAST式、文、型構造を表現するためのスキーマモデル、共用体型、種類を定義し、解析をサポートします。
- Python Code Structure Analysis - Pythonのコード構造、シンボル、モジュール、ファイル、プロジェクト設定、依存関係に関するデータモデルとスキーマを提供します。
- Structured Document Schemas - 構造化ドキュメントやセクションのデータモデル、検証ルール、変換戦略、コンテンツ要素を定義します。
- Error Handling Models - AI、設定、データベース、検証に関する、コアのエラー処理モデル、ドメイン固有のエラークラス、解決戦略を提供します。
- Knowledge Management Schemas - コーディングガイドライン、技術文書、運用ナレッジ、ロードマップなどのナレッジドメインを構造化するためのスキーマを定義します。
