# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

このパッケージは Gyomu システムの標準スキーマモデルとデータ構造を定義し、Python の AST およびコード分析、パッケージ構造分析、Conceptual Modeling、エラー処理、設定管理のための堅牢な Pydantic ベースのモデルを提供します。\n\n主な目的は、プロジェクト全体で共有スキーマ、型定義、エラー型、プロトコル、汎用ユーティリティを確立することです。Python Analysis、Concept、Document、Knowledge、Snapshot などの機能間でやり取りされるデータ契約を定義することで、パッケージ間の依存関係を疎結合に保ちながら、型安全性とデータの整合性を維持します。

## アーキテクチャ

`gyomu-schema` パッケージは、スキーマモデリング、エラー管理、設定、システムユーティリティの間で責務を分割する専用のコンポーネントで構成されています。Pydantic ベースのデータ構造は、Gyomu システムの個別のドメインを処理するように構造化されています。\n\nコアコードと抽象構文木解析は、専用のスキーマコンポーネントによって処理されます。Python 解析コンポーネントは、式、文、シンボル、クラス、関数、モジュール、依存関係のモデルを定義し、型処理のための専用の構造を備えています。これらのコードレベルのモデルを補完するものとして、Concept およびパッケージモデリングコンポーネントは、パッケージ依存関係分析、ディレクトリの事実、pyproject 分析、およびアーキテクチャ機能の構造を定義します。\n\n運用上の関心事は、専用のモジュールに分離されています。エラーハンドリングコンポーネントは、基本アプリケーションエラー、AI、設定、データベース、I/O、バリデーション、タイムアウトにわたるドメイン固有の失敗クラスを、運用フェーズや自動リトライ戦略とともに定義します。同時に、設定コンポーネントは、システムプロセス、コード解析、LLM 実行、ローダーのパラメータを管理します。最後に、ユーティリティモジュールは、ファイルシステム操作、プロジェクトスナップショット、オブジェクトシリアライズ、実行ヘルパーを提供してこれらのコンポーネントをサポートします。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-schema
```

## 依存関係

このパッケージは Python を必要とし、スキーマ定義、データ検証、シリアライゼーションに使用される Pydantic バージョン 2.x 向けに設計されています。また、Result 型を使用して明示的な成功および失敗の状態を管理するために `returns` ライブラリに依存しています。インストールする前に、実行環境がこれらの要件を満たしていることを確認してください。

## 開発

このパッケージの主たる目的は、標準的なスキーマ、型定義、エラー型、プロトコル、および汎用ユーティリティを提供することにより、Gyomuプロジェクト全体における共通の基盤として機能することです。Python Analysis、Concept、Document、Knowledge、Snapshotなどの機能間で受け渡されるデータ契約の中核となるソースとして機能することで、パッケージ間の依存関係を疎結合に保ちながら、型安全性とデータの整合性を維持します。 

貢献者は、この基盤を維持するために厳格なアーキテクチャポリシーを遵守しなければなりません。複数のGyomuパッケージ間で共有されるすべてのデータ契約はここに配置する必要があり、JSON、永続化、MCPなどの外部境界を越えるデータは、厳密にPydanticスキーマとして定義されます。これらのスキーマがAIコード生成、ドキュメント生成、ナレッジ生成に効果的に活用されるよう、アノテーションを省略してはなりません。さらに、誤用を防ぐために値型はそれぞれ異なる意味を表す必要があり、プロトコルは具象実装を持たずに共通インターフェースを定義し、エラー型はパッケージ間での一貫した処理のために共通の構造に従う必要があります。

独立したコアインフラストラクチャとしての役割を維持するため、このパッケージは他のGyomuパッケージに依存してはならず、特定のビジネスロジックを持たない汎用ユーティリティのみを含む必要があります。APIは可能な限りイミュータブルかつ宣言的に設計されるべきであり、内部処理のみで使用される実装詳細については、パブリックなPydanticスキーマとして公開するのではなく、隠蔽する必要があります。

## Public API

- Python ASTおよびコード分析スキーマ - 分析用のPython AST式、文、型、コード構造を表すスキーマモデルを定義します。
- パッケージおよびConceptモデリング - パッケージ分析、依存関係追跡、ディレクトリのファクト、機能およびパッケージのConceptに関する包括的なスキーマ定義を提供します。
- エラーハンドリングおよびリトライ戦略 - アプリケーション層のエラーハンドリングクラス、処理フェーズ、ドメイン固有のエラー、およびリトライ戦略を定義します。
- 設定およびプロセスオプション - システムプロセス、コード分析、LLM実行、ローダーの設定オプションとパラメータを定義します。
- システムユーティリティおよびファイル管理 - ファイルシステム管理、プロジェクトおよびファイルのスナップショット、シリアライズ、実行タイミング、非同期/同期実行ラッパーのユーティリティを提供します。
