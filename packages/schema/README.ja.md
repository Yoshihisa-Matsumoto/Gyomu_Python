# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuエコシステム全体で共通の基盤となる、標準的なデータモデル、構造スキーマ、および検証ルールを提供します。その主な目的は、PythonのAST解析、構造化ドキュメント、プロジェクト知識ベース、および堅牢なエラーハンドリング戦略のためのデータ契約を定義することです。 

共有の型、プロトコル、およびユーティリティ定義を確立することで、すべての機能モジュール間でデータの整合性と型安全性を確保します。アーキテクチャ全体で疎結合な依存関係を維持しながら、異なる機能間のシームレスな通信を容易にします。

## アーキテクチャ

このパッケージは、データ構造とシステム要件ごとに責任を分割する、連携するドメインスキーマとユーティリティコンポーネントの中核セットを中心に構成されています。基盤となるアーキテクチャでは、コード解析、ドキュメントのフォーマット、プロジェクト知識、堅牢なエラー管理を、それぞれ独立したモジュール式のサブシステムに分離しています。

コードおよび構造解析の責任は、特化したスキーマディレクトリによって処理されます。Pythonコンポーネントは、クラス、関数、モジュール、シンボルなどのコード構造をモデル化し、ネストされた型ディレクトリはAST表現、文、union型を定義します。同時に、ドキュメントコンポーネントは構造化されたコンテンツ要素、セクション、検証ルールを管理し、知識コンポーネントはコーディングガイドライン、運用詳細、技術リファレンスなどのドメイン固有のデータを構造化します。

フォールトトレランスやエラー管理などの横断的な運用要件は、アプリケーションのエラー階層、リトライポリシー、操作全体の解決戦略を定義する専用のエラーハンドリングスキーマに集約されています。これらのコンポーネントが連携することで、データモデリング、検証、シリアライズのための統一されたフレームワークが提供されます。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-schema
```

## 依存関係

このパッケージは、スキーマ定義、データ検証、シリアル化、および逆シリアル化に使用されるPydanticバージョン2.x向けに設計されています。ランタイムでの使用において、本パッケージはコアとなるデータ処理をpydanticに依存し、Success、Failure、およびResult型を使用して成功と失敗の明示的な表現を返します。

## 開発

複数の Gyomu パッケージ間で共有されるデータコントラクトは、この基盤内に配置する必要があります。貢献者は、JSON、永続化層、MCP インターフェースなどの外部境界で処理されるすべてのデータを Pydantic スキーマとして定義する必要があり、単一の処理フロー内に厳密にとどまる内部実装詳細は Pydantic モデルとして公開すべきではありません。値の誤割り当てを防ぎ厳密な境界を強制するため、開発者は識別子、パス、および意味のある値を、可能な限り専用の型で表現する必要があります。さらに、Pydantic スキーマのアノテーションは省略せずに網羅的に提供し、ランタイムの型情報としてだけでなく、AI を活用したコード生成、ドキュメント生成、および知識生成のための不可欠なコンテキストとしても機能するように確保する必要があります。

インターフェースと共有される抽象化は、厳格な依存関係および配置ルールに従う必要があります。開発者は、実装から分離されたインターフェースコントラクトとして Protocol を定義し、このパッケージを、複数のパッケージによって共有され、どの単一パッケージの特定の責務にも属さないインターフェースに限定すべきです。特定のパッケージの責務やユースケースに結びついた Protocol はそれぞれのパッケージ内に配置し、具象実装は依存関係と責務の正しい方向性に従って配置します。エラーハンドリングは、エコシステム全体で一貫したエラー管理を保証するために、すべての定義にわたって共通のエラー構造に従う必要があります。

このパッケージに実装されるすべてのユーティリティは、厳密に汎用的であり、特定の Gyomu パッケージに結びついたビジネスロジックを含まないようにする必要があります。貢献者は、堅牢なデータの整合性と型安全性を維持するために、API を可能な限りイミュータブルかつ宣言的に設計する必要があります。最後に、貢献者は他の Gyomu パッケージに対するこのパッケージのゼロ依存関係の状態を維持し、常に孤立した安定した共有基盤として機能し続けるように確保する必要があります。

## Public API

- Python AST and Type Models - Pythonの抽象構文木（AST）の式、文、型、コード構造要素を解析用にモデル化します。
- Structured Document Models - 構造化ドキュメントのモデル、要素、検証ルール、変換戦略を定義します。
- Project Knowledge Schemas - プロジェクトの知識、ガイドライン、運用詳細、技術リファレンスを表現するためのドメイン特化型スキーマを提供します。
- Error Handling and Recovery Schemas - 包括的なアプリケーションのエラー階層、リトライポリシー、オペレーション全体の解決戦略を定義します。
- Serialization and Utility Framework - シリアライズ、フォーマット検証、タイミング、実行ラッピング、ファイルシステム操作のためのユーティリティ関数を提供します。
