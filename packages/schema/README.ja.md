# Gyomu Schema

[US English](README.md) | JP 日本語

## 概要

このパッケージは、Gyomuプロジェクト全体で共有される基礎的なデータコントラクト、標準モデル、および構造スキーマを提供します。その主な目的は、PythonのAST解析、構造化ドキュメント、プロジェクト知識ベース、スナップショットのための標準型、プロトコル、エラーモデル、検証ルールを定義することです。 機能を担うコンポーネント間で明確なデータコントラクトを確立することにより、システム全体を通じて厳格な型安全性とデータの整合性を維持します。これにより、パッケージ同士が完全に疎結合を保ちながらシームレスに連携できるようになり、プロジェクト全体でのデータ交換において堅牢で保守性の高いアーキテクチャが保証されます。

## アーキテクチャ

このパッケージは、データ構造とシステム要件ごとに責任を分割する、専門特化したスキーマドメインとユーティリティフレームワークのコアセットを中心に構成されています。コード解析と構造表現は、ASTの式、文、クラス、関数、モジュール、型システムのモデルを定義する専用のPythonモジュールによって処理されます。

コード解析機能を補完するものとして、構造化ドキュメントスキーマがセクション、段落、リスト、テーブルなどのコンテンツ要素を管理し、プロジェクトナレッジスキーマがコーディングガイドライン、ロードマップ、技術リファレンスなどのドメイン固有の情報を捉えます。堅牢な横断的処理は、包括的なエラー階層、ドメイン固有の障害定義、およびリトライ解決戦略を提供する専用のエラー処理コンポーネントによってサポートされます。

最後に、シリアライゼーションおよびユーティリティフレームワークがこれらのドメイン間で連携して、フォーマット検証、データ変換、タイミング、実行監視、ファイルシステム操作を提供し、構造モデルとエラー戦略を統合されたアーキテクチャにまとめ上げます。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-schema
```

## 依存関係

このパッケージは、スキーマ定義、データ検証、シリアライゼーション、およびデシリアライゼーションに Pydantic Version 2 を中心として設計されているため、Pydantic バージョン 2.x が必要です。

ランタイムの使用においては、`returns` パッケージに依存しており、Success、Failure、および Result 型を使用して明示的な成功と失敗の表現を処理します。

## 開発

コントリューターは、このパッケージをGyomuエコシステムの基礎となる依存関係ゼロのレイヤーとして維持する必要があります。複数のパッケージ間で共有されるすべてのデータコントラクトはここに配置し、JSON、永続化、MCPレイヤーなどの外部境界にはPydanticスキーマを使用する一方、内部の実装詳細は隠蔽します。値の混同を防ぎ厳格な型安全性を確保するため、コントリューターはIDやパスなどの異なるConceptを明示的な型として表現し、プリミティブ執着を避ける必要があります。さらに、Pydanticスキーマのアノテーションは、ランタイムの型整合性の強制と、AI支援によるコード、ドキュメント、知識生成の駆動という二重の目的を果たすため、決して省略してはなりません。

プロトコル定義とエラー処理には、慎重な境界管理が求められます。プロトコルは、単一のパッケージの責務に属さない共有インターフェースコントラクトを表す場合にのみここに定義し、パッケージ固有 ユースケースではプロトコルをローカルに保持する必要があります。実装は適切な依存関係の方向に従わなければなりません。すべてのエラー型はパッケージ間での一貫したエラー処理を保証するために共通構造に準拠する必要があり、ユーティリティは厳格に汎用的であり、ビジネスロジックを持たないように維持しなければなりません。最後に、コントリューターは、アーキテクチャの進化に伴ってデータの整合性と疎結合が維持されるよう、すべてのAPIをイミュータブルかつ宣言的に設計することが求められます。

## Public API

- Python AST and Type Models - 分析対象のPython抽象構文木（AST）の式、文、型、およびコード構造要素をモデル化します。
- Structured Document Models - 構造化ドキュメントモデル、要素、検証ルール、および変換戦略を定義します。
- Project Knowledge Schemas - プロジェクトの知識、ガイドライン、運用詳細、技術リファレンスを表現するためのドメイン固有スキーマを提供します。
- Error Handling and Recovery Schemas - アプリケーションのエラー階層、リトライポリシー、およびオペレーション全体にわたる解決戦略を包括的に定義します。
- Serialization and Utility Framework - シリアライズ、フォーマット検証、タイミング、実行ラッパー、ファイルシステム操作のためのユーティリティ関数を提供します。
