# Gyomu AI

[US English](README.md) | JP 日本語

## 概要

このパッケージはGyomuプロジェクトのAI実行基盤として機能し、Pydantic AIをベースにしたAI処理の管理と実行のための堅牢なフレームワークを提供します。主な目的は、AIプロバイダやSDK間の差異を吸収し、モデルルーティング、実行ポリシー、エラーハンドリングのための統一されたメカニズムを提供することです。

テキスト、オブジェクト、埋め込みの生成に関する標準化された機能を提供することで、このフレームワークは、利用側のパッケージが特定のプロバイダの実装から独立した状態を維持できるようにします。この設計により、下位のベンダーインターフェースに直接依存することなく、AI機能をシームレスに統合できる一貫性のある環境が実現します。

## アーキテクチャ

`gyomu-ai` パッケージは、モデル参照、実行管理、ツール統合、エラー処理に責任を分割する、連携するコンポーネント群によって構成されています。

基盤となるモデル定義と列挙型はコアモデルモジュールに配置され、AIモデルとバケットの識別子を提供します。実行コンポーネントは、テキスト、オブジェクト、および埋め込みの生成に関するメタデータ、結果、トークン使用統計を収集しながら、実行時パラメータ、実行コンテキスト、ポリシー、ストリーミングイベントを管理します。

このパッケージは、プロバイダー非依存の実行ロジックとモデルルーティングを Pydantic AI プロバイダー統合に委譲します。このコンポーネントは Pydantic AI と連携して、エージェントの作成、プロンプトの構築、ストリーム処理、およびツールマッピングを処理します。同時に、ツールモジュールは、AIツール実行のためのコアビジネスロジック、設定、および結果処理を提供します。最後に、専用のエラーモジュールおよびルーティングモジュールが、アプリケーション固有の例外型と、すべての操作にわたる標準化されたマッピングを定義します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-ai
```

## 依存関係

このパッケージは Pydantic AI Version 2 向けに設計されています。

ランタイム依存関係には、一般的な LLM 処理用の pydantic ai、Success、Failure、Result を使用した明示的な成功・失敗表現のための returns、スキーマおよび共通型のリポジトリとしての gyomu-schema、そして入出力などの一般的なインフラストラクチャ処理用の gyomu-infra が含まれます。

## 開発

コントリビューターは、AIプロバイダー固有のSDKが消費者側に直接公開されないようにすることで厳格な抽象化境界を強制し、すべてのやり取りがGyomuの定義済みの抽象化層を介してのみ行われるようにする必要があります。アーキテクチャ上の決定では、一元管理されたモデルレジストリと実行ポリシーに依存し、ハードコードされたエンドポイントではなく、設定されたルーティング機構を介してすべてのAIリクエストを排他的にルーティングする必要があります。システムの復元力を維持するため、コントリビューターは、実行フェーズや根本原因などの診断情報をキャプチャする構造化されたエラーハンドリングを実装し、プロバイダー固有の出力を標準的な結果形式に体系的にマッピングすることが求められます。

実行ロジックには、一時的な障害に対処するための定義済みのリトライ戦略と、利用可能な場合に代替の実行パスへ操作をシームレスにリダイレクトするフォールバック機構を組み込む必要があります。エージェント作成、ツールマッピング、プロンプト構築、ストリーム処理のためにPydantic AIを統合する場合、コントリビューターは、テキスト、オブジェクト、および埋め込み生成のためのこれらの統一された実行ワークフローを維持する必要があります。標準化されたルーティング、リトライポリシー、またはエラーマッピング構造をバイパスするコードのコントリビューションは、実行プラットフォームの中核となるアーキテクチャに違反するため、受け入れられません。

## Public API

- Pydantic AI Integration - モデルの実行、プロンプトの構築、エージェントの作成、およびストリーミング機能のために Pydantic AI と統合します。
- Execution Management - AI とのやり取りにおける実行コンテキスト、ランタイムポリシー、ストリーミングイベント、トークン使用統計、および結果構造を管理します。
- AI Tool Execution - AI ツール実行のためのコアなドメインロジック、定義、設定、および結果の処理を提供します。
- Model Routing and Registry - AI モデルのやり取りを設定するためのモデルレジストリ、ルーティングテーブル、および初期化ルーチンを提供します。
- Error Handling and Mapping - アプリケーション固有のエラー型、例外マッピング、および AI 操作に対する堅牢なエラーハンドリングを定義します。
