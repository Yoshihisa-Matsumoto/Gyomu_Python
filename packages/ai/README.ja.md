# Gyomu AI

[US English](README.md) | JP 日本語

## 概要

Gyomu AI は Gyomu プロジェクトの AI 実行基盤として機能する Python ライブラリであり、Pydantic AI に対してプロバイダーに依存しない統合された抽象化レイヤーを提供します。その主要な目的は、さまざまな AI プロバイダーや SDK の差異を吸収し、AI 機能を利用するアプリケーションが特定のプロバイダーに直接依存しないようにすることです。

このパッケージは、実行ランタイム、パラメータ、ポリシー、ツール実行、モデルレジストリ、動的モデルルーティングに対する一貫したフレームワークを提供することでこれを実現します。AI 実行、モデルルーティング、リトライ、フォールバック、エラー処理などの操作を一元化し、堅牢で適応性の高い AI アプリケーションの開発を効率化します。

## アーキテクチャ

Gyomu AIは、プロバイダ統合、実行管理、ツール処理、モデル定義、エラー管理に責任を分割する、連携するコンポーネント群を中心に構成されています。

プロバイダ統合コンポーネントはPydantic AIへのブリッジとして機能し、モデルレジストリ、エージェント作成、プロンプト構築、およびネイティブ構文から標準フォーマットへのマッピングを処理します。実行ランタイムコンポーネントは、テキスト、オブジェクト、ストリーミング生成のための実行環境、ランタイムパラメータ、設定ポリシー、オブザーバ、およびトークン使用量統計を管理します。

これらの運用層を支えるものとして、ツールコンポーネントはツール実行のコアとなるドメインロジックと結果構造を格納し、モデルコンポーネントは基礎的なAIモデル表現と識別キーを定義します。最後に、エラー処理コンポーネントは専用のルーティングエラーを含むアプリケーション固有の例外を管理し、操作全体にわたって標準化されたエラーレポートを保証します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-ai
```

## 依存関係

このパッケージは Pydantic AI バージョン 2.x の互換性を目的として設計されています。 

ランタイム操作において、一般的な LLM 処理には pydantic ai を、Success、Failure、Result を用いた明示的な成功と失敗の表現には returns を、スキーマと共通型には gyomu-schema を、I/O などの一般的なインフラストラクチャ処理には gyomu-infra を使用します。

## 開発

コントリビューターは、利用側パッケージと背後のAIプロバイダーSDKを疎結合にする抽象化レイヤーを厳格に維持しなければなりません。すべてのAIインタラクションは、プロバイダー固有のロジックを直接呼び出すのではなく、定義されたルーティング機構を排他的に経由する必要があります。コードを追加する際はこの境界を尊重し、プロバイダー固有の結果型が標準化された Gyomu の結果へ体系的にマッピングされること、および背後のSDKの変更がこの実行基盤の内部にとどまることを担保してください。

実行パイプラインへの機能拡張においては、耐障害性と可観測性が必須要件となります。AI実行時の一時的な障害は定義されたリトライ戦略に従って捕捉および処理されなければならず、フォールバック機構は、利用可能な場合に代替の実行パスへリクエストをルーティングするためシームレスに動作する必要があります。さらに、すべての統合されたAI操作にわたって予測可能な動作を保証するため、すべての実行失敗は捕捉され、実行フェーズや根本原因を含む包括的な診断詳細をカプセル化した構造化エラーとして再送出されなければなりません。

## Public API

- AI Provider Integration - 標準化されたエラー、結果、ツールフォーマットを使用して、Pydantic AI モデル、レジストリ、エージェントを統合します。
- Execution Runtime Management - AI 操作の実行コンテキスト、ランタイムパラメータ、ツールループポリシー、オブザーバー、トークン使用統計を管理します。
- AI Tool Execution - AI ツールの実行に関するドメインロジック、設定、結果構造を定義します。
- Model Routing and Configuration - 動的なモデルルーティング規則およびルーティングエラーハンドリングの設定と実行を行います。
- Core Domain Models - AI モデル表現およびアプリケーション固有のエラーに関するコアデータ構造を定義します。
