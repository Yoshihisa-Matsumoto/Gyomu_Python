# Gyomu Infra

[US English](README.md) | JP 日本語

## 概要

gyomu-infra パッケージは、Gyomu エコシステムの基盤インフラストラクチャ層として機能します。その主な役割は、ファイル処理、設定読み込み、アーカイブ、データベースアクセスなどの外部環境とのやり取りや具体的な処理タスクを、単一の共有モジュールに集約することです。 

外部ライブラリや実行環境に依存する操作を統合することで、上位パッケージが実装詳細に直接依存するのを防ぎます。Pydantic と統合された CSV パーシング、高度なファイルシステムおよびストリーム操作、トランザクション管理を備えた SQLAlchemy ベースのデータベース永続化、ならびに営業日カレンダーやパラメータ解決などの専門的なドメインサービスを含む、堅牢なコアユーティリティを提供します。

## アーキテクチャ

このパッケージは、コアインフラストラクチャとドメインの責務を分割する、専門化された連携コンポーネント群によって構成されています。データ処理機能は、CSVのパースとシリアライゼーションを行う専用モジュールがPydanticモデルと統合されて担うほか、遅延評価される使い捨てストリームやバイトストリームのファイル操作を管理するストリーム処理ユーティリティによって構成されています。\n\n永続データアクセスはデータベース管理コンポーネントを中心に構築されており、SQLAlchemyのリポジトリとトランザクション制御を利用してデータ管理およびクエリプロトコルを実装しています。さらに、専門化されたドメインサービスが、ビジネスカレンダーの計算、祝日サービス、および変数の変換を実行します。\n\n最後に、堅牢なファイルシステムおよびシステムユーティリティのセットが、ファイルI/O操作、列挙、検索、アクセス管理、プロセス実行、ハッシュ化、およびアーカイブをサポートします。これらのコンポーネントが連携することで、システムのストレージ、パース、およびドメインロジックをサポートする統合されたインフラストラクチャ層を提供します。

## インストール

uvを使用してインストールします。

```bash
uv add gyomu-infra
```

## 依存関係

This package is designed for Pydantic version 2.x compatibility. \n\nFor runtime operations, it relies on Pydantic for schema definition, data validation, serialization, and deserialization. Additionally, it uses the returns library for explicit success and failure expressions via Success, Failure, and Result, and SQLAlchemy for database access.

## 開発

コントリューターは、上位層がインフラストラクチャの実装詳細に直接依存しないよう、すべての入出力操作、副作用、および外部ライブラリとの連携をこのパッケージ内に厳格に隔離する必要があります。特定の外部APIは共通インターフェースおよび共有ユーティリティの背後にカプセル化し、ファイルシステム、データベース、設定、データ変換ツール間での明確な関心の分離を確保します。外部データを処理する際はスキーマ検証を活用し、データベースアクセスにおいては、永続化の仕組みを利用側のコードから隠蔽するリポジトリやマッパーを通じて、責務の厳格な分離を維持する必要があります。

すべてのエラー処理では、ネイティブ例外を、操作の起点とコンテキストを追跡可能な共通のエラーモデルに変換しなければなりません。コントリューターが、このインフラストラクチャ層に特定のアプリケーションビジネスロジックやドメイン知識を持ち込むことは厳に禁止されています。パッケージのいかなる変更においても、上位パッケージが特定の外部ライブラリおよび実行環境から完全に疎結合を維持するという設計制約が守られなければなりません。

## Public API

- CSV データ処理 - Pydantic データモデルと統合された CSV データの読み込み、パース、シリアライズ、および処理設定を行います。
- ファイルシステムユーティリティ - ファイルの入出力、検索、列挙、およびアクセス管理のための堅牢なファイルシステムユーティリティを提供します。
- データベース管理 - データベース接続、SQLAlchemy のリポジトリパターン、トランザクション、およびエラー処理を管理します。
- 業務ドメインサービス - 営業日カレンダーの計算、休日サービス、パラメータアクセス、および変数変換を実行します。
- コアシステムユーティリティ - 遅延ストリーム処理、プロセス実行、ハッシュ化、アーカイブなどの汎用ユーティリティをサポートします。
