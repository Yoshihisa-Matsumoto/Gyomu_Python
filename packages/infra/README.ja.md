# Gyomu Infra

[US English](README.md) | JP 日本語

## 概要

Gyomu Infrastructureは、Gyomuエコシステム向けに堅牢な共有インフラストラクチャユーティリティおよびサービスを提供するコアパッケージです。ファイルやストリームの入出力、構造化されたCSV処理、ファイルシステム操作、SQLAlchemy経由でのデータベース永続化など、外部環境接続に関する処理を標準化し、処理することを主目的としています。 

このパッケージは、営業日カレンダーの計算、市場の休日リポジトリ、パラメータ変換サービスなど、ドメイン特有のインフラストラクチャに関わる関心事をカプセル化します。外部ライブラリや実行環境に依存する操作を一元化することで、上位パッケージがインフラストラクチャの実装詳細に直接依存するのを防ぎ、クリーンアーキテクチャを担保します。

## アーキテクチャ

このパッケージは、データ処理、ファイルシステム操作、ドメイン固有のサービスに責務を分割する、特化した協調的インフラストラクチャコンポーネント群として構成されています。コアユーティリティが構造化データのパース、ファイルの入出力、ストリーム処理を管理し、専用の永続化層がSQLAlchemyを介したリレーショナルデータベースの接続とトランザクションを処理します。

責務はモジュール式のディレクトリに明確に分離されています。CSVコンポーネントは読み込み、書き込み、モデル検証を処理し、ファイルシステムモジュールは堅牢なファイルの列挙、検索、排他アクセス処理を提供します。ストリーム処理コンポーネントは、遅延評価されるデータパイプラインとバイトストリームの入出力管理を行います。

動的な実行コンテキストをサポートするため、ドメイン固有の関心事がカプセル化されています。変数変換コンポーネントは日付やパラメータのプレースホルダーを解決し、日付コンポーネントはキャッシュされた市場の休日リポジトリを使用してビジネスカレンダーの計算を行います。これらのコンポーネントが協調して動作し、アプリケーションワークフローに対して信頼性の高いインフラストラクチャサービスを提供します。

## インストール

uv を使用してインストールします。

```bash
uv add gyomu-infra
```

## 依存関係

このパッケージはPydanticバージョン2.xとの互換性を目的に設計されています。

ランタイム実行において、スキーマ定義、データ検証、シリアル化および逆シリアル化をPydanticに依存しています。また、Success、Failure、Resultを通じた明示的な成功および失敗処理を提供するためにreturnsを使用し、データベースアクセスにはSQLAlchemyを利用します。

## 開発

貢献者は、上位層が実装詳細に直接依存しないよう、外部ライブラリの API や副作用の強い I/O 操作を共通のインフラストラクチャインターフェースの背後に厳格にカプセル化する必要があります。ファイルシステム、データベース、設定の読み込み、データ変換は、関心の分離を厳格に維持し、入力される外部データはスキーマを通じて一貫して検証されなければなりません。永続化ロジックでは、データベース固有の詳細から利用者を保護するためにリポジトリとマッパーを明確に分離する必要があり、すべてのエラーは、操作の追跡と失敗箇所の特定のためにコンテキストを保持する統一されたエラーモデルにマッピングされなければなりません。

アーキテクチャの整合性を維持するため、貢献者はこのパッケージにドメイン固有のビジネスロジックやアプリケーション固有のルールを一切含めず、Gyomu エコシステムの再利用可能な基盤であり続けられるようにする必要があります。外部ライブラリや実行環境の統合はすべて標準化されたインターフェースの内側にラップする必要があり、これにより、より広範なシステムが具象実装に結合することなく外部システムと対話できるようになります。

## Public API

- CSV データ処理 - Pydantic の検証を使用して、構造化された CSV データおよび設定モデルの読み取り、書き込み、パースを行います。
- ファイルシステム操作 - ファイル I/O、検索、列挙、および排他アクセス処理を含む堅牢なファイルシステム操作を提供します。
- ストリーム処理 - パイプラインデータを処理するための、遅延評価によるストリーム処理とバイトストリーム I/O ユーティリティをサポートします。
- 変数とパラメータの解決 - 動的な実行コンテキストをサポートするために、日付やパラメータのプレースホルダーを解決および置換します。
- 営業日カレンダーサービス - キャッシュされたリポジトリインスタンスを使用して、営業日カレンダーの計算および市場の休日サービスを実行します。
- データベースインフラストラクチャ - リレーショナルデータベースの接続、トランザクション、および SQLAlchemy ベースのリポジトリモデルを管理します。
