# Gyomu Infra

[US English](README.md) | JP 日本語

## 概要

このコアインフラストラクチャパッケージは、Gyomuエコシステム向けに設計された堅牢なユーティリティとサービスを提供します。主な目的は、ファイルおよびストリームの入出力、構造化されたCSV処理、ファイルシステム操作、SQLAlchemyを通じたデータベース永続化など、外部環境とのインタラクションを標準化し処理することです。

このパッケージには、営業日カレンダー計算、市場の休日リポジトリ、パラメータ変換サービスなど、ドメイン特有の重要なインフラストラクチャに関わる関心がカプセル化されています。外部ライブラリや実行環境に依存する操作を集中管理することで、上位パッケージが低レベルの実装詳細から疎結合に保たれるようにします。

## アーキテクチャ

gyomu-infraパッケージは、データ処理、ストレージ、ドメインロジックの各領域にインフラストラクチャの責任を分割する、専門化されたモジュール群で構成されています。パッケージ構造は、低レベルなシステムユーティリティとドメイン固有のサービスを分離し、ファイル処理、データベース永続化、ビジネス計算の間で構造化された連携を可能にします。

データ処理とファイル操作は、Pydanticの検証機能を備えた構造化CSVパース、ファイルシステム操作、遅延ストリーム処理のための専用コンポーネントによって管理されます。これらのI/Oおよびストリームのユーティリティは、より広範なアプリケーションへとデータを供給する基盤データパイプラインを提供します。

永続化およびドメイン固有の操作は、データベースリポジトリの実装と専門化された計算サービス内にカプセル化されています。リレーショナルデータベースとのやり取りはSQLAlchemyベースのリポジトリを介して処理され、ドメインロジックはキャッシュされた市場休日リポジトリを活用してビジネスカレンダーの計算や動的なパラメータ変換を実行します。これらが連携するコンポーネント群一体となって、システム統合とデータ管理のためのまとまりのあるインフラストラクチャ層を実現します。

## インストール

uvを使用してインストールします。

```bash
uv add gyomu-infra
```

## 依存関係

このパッケージはPydanticバージョン2.xを必要とします。Pydanticバージョン2専用に設計されているためです。 

ランタイム依存関係として、スキーマ定義、データ検証、シリアライゼーション、およびデシリアライゼーションにPydanticを利用します。また、Success、Failure、およびResultによる明示的な成功と失敗の表現にreturnsを、データベースアクセスにSQLAlchemyを使用します。

## 開発

コントリューターは、すべての入出力操作、副作用、および外部ライブラリのAPIをこのパッケージ内に分離し、関心事の分離を厳格に徹底する必要があります。上位パッケージが外部環境や特定のサードパーティライブラリへの直接的な依存関係を持つことを防ぐため、ファイルシステム、データベース、設定読み込み、およびデータ変換の実装詳細カプセル化を完全に維持しなければなりません。さらに、ドメイン固有のビジネスロジックがこのインフラストラクチャ層に混入してはならず、すべての実装はアプリケーション固有のルールを内包するのではなく、汎用的なユーティリティコンポーネントであるべきです。

アーキテクチャの整合性を維持するため、永続化操作では、リポジトリやマッパーなどの厳格な境界を利用して、データベースアクセスの詳細を利用側のコードから切り離す必要があります。外部ソースから取得したデータはスキーマによる検証が必要であり、外部ドライバによってスローされた未処理の例外はキャッチした上で、操作と失敗箇所のコンテキストを保持する統一されたエラーモデルに変換しなければなりません。Gyomuエコシステムの疎結合な性質を維持するため、隠れた密結合を持ち込むコントリビューション、生の外向きAPIを上位層に公開するコントリビューション、あるいはドメイン知識をこれらのユーティリティコンポーネントに混入させるコントリビューションは拒否されます。

## Public API

- CSVデータ処理 - Pydanticのバリデーションを使用して、構造化されたCSVデータおよび設定モデルの読み取り、書き込み、パースを行います。
- ファイルシステム操作 - ファイルのI/O、検索、列挙、排他制御など、堅牢なファイルシステム操作を提供します。
- ストリーム処理 - パイプラインデータを処理するための遅延ストリーム処理およびバイトストリームI/Oユーティリティをサポートします。
- 変数およびパラメータの解決 - 日付やパラメータのプレースホルダーを解決および変換し、動的な実行コンテキストをサポートします。
- ビジネスカレンダーサービス - キャッシュされたリポジトリインスタンスを使用して、営業日カレンダーの計算や市場の祝日サービスを実行します。
- データベースインフラストラクチャ - リレーショナルデータベースの接続、トランザクション、およびSQLAlchemyベースのリポジトリモデルを管理します。
